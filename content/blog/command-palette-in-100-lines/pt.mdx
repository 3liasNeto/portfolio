Paletas de comandos viraram padrão em ferramentas de dev. A boa notícia: o navegador já entrega a parte difícil.

## O segredo é o `<dialog>`

O elemento `<dialog>` aberto com `showModal()` já cuida do foco, do fundo escurecido e da tecla `Esc`. Sobra para nós só a lista.

```tsx
const results = commands.filter((command) =>
  command.label.toLowerCase().includes(query.toLowerCase()),
);

function onKeyDown(e: React.KeyboardEvent) {
  if (e.key === "ArrowDown") setActive((i) => (i + 1) % results.length);
  if (e.key === "ArrowUp") setActive((i) => (i - 1 + results.length) % results.length);
  if (e.key === "Enter") results[active]?.run();
}
```

## O atalho global

Um único listener no `window` abre e fecha a paleta com ⌘K ou Ctrl+K. Lembre de chamar `preventDefault()` — o navegador também usa esse atalho.

<Callout type="tip">
  Use `role="combobox"` no input e `aria-activedescendant` apontando para o item ativo: leitores de tela anunciam a navegação sem mover o foco.
</Callout>
